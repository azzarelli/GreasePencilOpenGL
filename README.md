# Grease Pencil OpenGL App for plain objects

Implementing a Greese Pencil functionality for drawing 2D shapes over 3D meshes.

This is for a downstream project + a nice learning experience.


Current Work:
- A Simple CPU-BVH implementation with a depth-ordered equal split strategy
- A Ray-AABB debugging intersection program to show the BVH working
- A Ray-AABB traversal with the slab method
